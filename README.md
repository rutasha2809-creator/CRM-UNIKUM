# Уникум — учёт детского учебного центра

Веб-приложение: справочники (ученики, педагоги, статьи, направления, тарифы),
журнал занятий с автоматическим списанием абонементов, журнал операций
с загрузкой банковской выписки и отчёты — БДДС, БДР, абонементы, P&L,
рентабельность, налоги УСН.

## Как устроено

* `index.html` — страница и экран входа
* `styles.css` — оформление
* `app.js` — вся логика и отчёты
* `config.js` — адрес базы данных

Данные хранятся в Supabase (проект FREELAB, таблицы с префиксом `un_`).
Вход — по почте и паролю; работать могут только адреса из списка
«Справочники → Доступ».

## Обновление сайта

Запустить `ОБНОВИТЬ САЙТ.bat` в папке проекта.
