# Уникум — учёт детского учебного центра

Веб-приложение: справочники НСИ (ученики, педагоги с моделью оплаты, статьи с
признаками БДР и налоговой базы, направления, предметы, шаблоны абонементов),
каталог постоянных абонементов с выставлением в один клик, учёт оплат и долгов,
журнал занятий с автоматическим списанием, журнал операций с загрузкой
банковской выписки и отчёты — БДДС, БДР, абонементы, P&L, рентабельность
центра и по разрезам (направления, педагоги, абонементы, группы), зарплата
педагогов, налоги УСН.

## Как устроено

* `index.html` — страница и экран входа
* `styles.css` — оформление
* `app.js` — вся логика и отчёты
* `config.js` — адрес базы данных

Данные хранятся в Supabase (проект FREELAB, таблицы с префиксом `un_`).
Вход — по почте и паролю; работать могут только адреса из списка
«Справочники → Доступ».

## Обновление сайта

Запустить `ОБНОВИТЬ САЙТ.bat` в папке `site`. При первом запуске он сам
свяжет папку с репозиторием. Нужен установленный Git для Windows.
